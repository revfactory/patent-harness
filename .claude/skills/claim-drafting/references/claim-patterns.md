# 청구항 문형 예시

아래 예시는 문형을 보여 주기 위한 가상 사례(등산화 밑창)다. 구성과 수치는 사건마다 특허성 판단과 시험 계획을 따라 정하고, 예시 문구를 그대로 옮기지 않는다.

## 1. 물건(구조) 독립항

```
【청구항 1】
등산화용 밑창으로서,
고무 재질의 밑창 본체; 및
상기 밑창 본체의 접지면에 형성된 복수의 돌기;를 포함하고,
상기 밑창 본체는 앞꿈치 영역과 뒤꿈치 영역으로 구획되며,
상기 앞꿈치 영역의 돌기는 제1 고무로 형성되고,
상기 뒤꿈치 영역의 돌기는 상기 제1 고무보다 경도가 높은 제2 고무로 형성되는 것을 특징으로 하는 등산화용 밑창.
```

- 구성마다 줄을 바꾸고 세미콜론으로 나누면 구성 분해와 대비표 작성이 쉽다.
- 기능 표현("미끄럼을 줄이는")을 쓸 때는 그 기능을 내는 구조(영역 배치, 재료군)를 같은 항이나 종속항에 둔다.

## 2. 수치 한정 종속항

```
【청구항 5】
제1항에 있어서,
상기 제1 고무는, 두께 6 mm 이상의 시편을 온도 23℃에서 측정한 쇼어 A 경도가 50 이상 60 이하인 등산화용 밑창.
```

- 값을 좌우하는 측정 조건(시편 두께, 온도)은 청구항에 직접 쓴다.
- 범위 경계마다 실시예·비교예를 둔다. 경계 한쪽에만 데이터가 있으면 임계적 의의를 주장할 수 없다.

## 3. 재료 마쿠시(택일) 종속항

```
【청구항 3】
제1항 또는 제2항에 있어서,
상기 제1 고무는 천연고무, 스티렌-부타디엔 고무 및 부타디엔 고무로 이루어진 군에서 선택된 하나 이상을 포함하는 등산화용 밑창.
```

## 4. 조합(완제품) 독립항

```
【청구항 8】
갑피; 및
상기 갑피의 하부에 접합된 제1항 내지 제7항 중 어느 한 항에 따른 등산화용 밑창;을 포함하는 등산화.
```

## 5. 제조 방법 독립항

```
【청구항 10】
제1 고무로 앞꿈치 영역의 돌기 성형체를 만드는 단계;
상기 제1 고무보다 경도가 높은 제2 고무로 뒤꿈치 영역의 돌기 성형체를 만드는 단계;
상기 두 돌기 성형체를 금형에 배치하고 밑창 본체용 고무와 함께 가황 성형하는 단계; 및
…를 포함하는 등산화용 밑창의 제조 방법.
```

- 방법 청구항은 단계 순서가 권리 범위를 한정하는지 명세서에서 밝힌다.

## 6. 사용 방법 청구항

소비자가 실시하는 사용 방법은 권리 행사 대상이 개인이라 효용이 낮다. 대신 "사용 방법을 표시한 표시부를 갖는 밑창"처럼 물건으로 바꿔 쓸 수 있는지 검토한다. 단, 표시된 정보만으로는 기술적 특징이 되기 어렵다.

## 7. 젭슨형

```
고무 재질의 밑창 본체와 접지면의 복수의 돌기를 갖는 등산화용 밑창에 있어서,
{특징 구성}을 특징으로 하는 등산화용 밑창.
```

전제부는 공지라고 인정하는 효과가 있으므로, 전제부에 넣을 구성이 정말 공지인지 확인한 뒤 쓴다.
