# 출원 전략과 일정

filing-strategist가 따르는 절차다. 출원 전략의 목적은 세 가지다. 공개로 신규성을 잃지 않는 것, 기한을 놓치지 않는 것, 돈을 써야 할 나라에만 쓰는 것.

기한 규칙과 제도 요지는 `references/deadlines.md`에 있다. 날짜를 계산하기 전에 읽는다.

## 1. 권리 형태 결정

| 질문 | 판단 |
| --- | --- |
| 핵심이 기술 구성(구조·재료·방법)인가 | 특허를 기본으로 한다 |
| 수명이 짧은 단순 구조이고 빠른 등록이 중요한가 | 실용신안을 검토한다. 한국 실용신안도 현재는 심사를 거치며 존속기간은 출원일부터 10년이다. 방법 발명은 실용신안 대상이 아니다 |
| 외관(형상, 모양, 인쇄 패턴)이 차별점인가 | 디자인 등록을 함께 검토한다. 부분 디자인도 가능하다 |
| 브랜드로 쓸 이름·형상이 있는가 | 상표(입체상표 포함)를 별도 검토 대상으로 적는다 |

여러 형태를 함께 쓸 때는 어떤 형태가 무엇을 막는지 표로 나눈다.

## 2. 국가·경로 결정

국가 후보를 세 기준으로 나눠 근거를 쓴다.

| 기준 | 의미 | 근거 자료 |
| --- | --- | --- |
| 시장국 | 제품을 팔 나라 | 시장 근거(market-analyst) |
| 생산국 | 부품·제품을 만들 나라 | 공급망 정보(없으면 확인 질문으로) |
| 경쟁사 거점 | 경쟁사가 존속 권리를 가진 나라 | 자유실시 분석(fto-analyst) |

- 두 나라 이상이면 PCT로 결정을 30개월까지 미루는 안을 기본으로 비교한다.
- 한 나라만 확실하면 파리조약 우선권으로 12개월 안에 직접 출원하는 안과 비용을 비교한다.

## 3. 일정표 작성

1. 기준일: 예정 최초 출원일. 정해지지 않았으면 오늘부터 30일 뒤로 가정하고 가정임을 적는다.
2. 기준일에서 각 기한을 실제 날짜로 계산한다. `references/deadlines.md`의 기간 표를 쓴다.
3. 시험 계획의 데이터 확보 예정일을 같은 표에 넣어, 국내 우선권·PCT 출원 전에 데이터가 나오는지 확인한다.
4. 기한이 휴일이면 다음 영업일로 넘어가는 나라가 많지만, 일정표에는 원래 날짜를 쓰고 여유를 둔다.

## 4. 공개 통제

- 출원 전 공개 금지 대상: 시제품 사진, 발표, 블로그·SNS, 제안서, 크라우드펀딩, 박람회, 투자 설명 자료, 외부 시험기관 의뢰서.
- 외부 협력사(시험기관, 부품 공급사, 디자인 업체)에는 비밀유지계약을 먼저 맺는다.
- 공지예외(한국 12개월)는 사고 대비책으로만 둔다. 유럽은 원칙적으로 공지예외가 없고, 중국은 범위가 좁다. 해외 출원 계획이 있으면 공개 뒤 출원으로 해외 권리를 잃을 수 있다.

## 5. 우선심사·조기 권리화

- 실시 중이거나 실시 준비 중인 출원, 전문기관 선행기술조사를 의뢰한 출원 등은 우선심사 대상이 될 수 있다. 요건은 특허청 고시로 바뀌므로 최신 고시 확인을 체크리스트에 넣는다.
- 우선심사는 빠른 등록에 유리하지만, 시험 데이터를 보강하기 전에 심사가 끝날 수 있다. 데이터 확보 일정과 함께 판단한다.

## 6. 출력 형식

```
# 출원 전략과 일정
> 기준일 가정: YYYY-MM-DD (가정이면 '가정'이라고 표시)
## 권리 형태 결정표
## 국가·경로 결정표
## 일정표 (날짜 | 할 일 | 근거 기한 | 담당)
## 출원 전 체크리스트
- [ ] …
## 변리사에게 확인할 질문
## 비용 등급과 가정
```

- 체크리스트는 Markdown 체크 상자(`- [ ]`)로 쓴다.
- 수수료와 대리인 비용은 바뀌므로 확정 금액으로 쓰지 않는다. 금액을 적으려면 특허청 수수료 안내 페이지를 찾아 출처와 확인 날짜를 붙인다.
