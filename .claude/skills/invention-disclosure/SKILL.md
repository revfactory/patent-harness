# 발명 발굴과 발명신고서

invention-miner와 whitespace-strategist가 따르는 절차다. 발명신고서는 이후 모든 단계(검색, 특허성 판단, 청구항, 명세서)의 입력이다. 여기서 과제와 구성이 흐리면 뒤 단계가 모두 흐려진다.

## 1. 발명 추출

입력 자료를 읽고 아래 다섯 칸을 채운다. 칸마다 출처를 `[자료: 파일·쪽]` 또는 `[추론]`으로 표시한다.

| 칸 | 질문 | 나쁜 예 | 좋은 예 |
| --- | --- | --- | --- |
| 기술 과제 | 기존 기술의 어떤 한계를 푸는가 | 밑창이 미끄럽다 | 경도가 하나인 고무 밑창은 젖은 암반에서 앞꿈치 돌기가 충분히 변형되지 않아 접지 면적이 작다 |
| 해결 구성 | 무엇을 어디에 어떻게 두는가 | 특수 고무 | 앞꿈치 영역의 돌기만 뒤꿈치보다 경도가 낮은 고무로 만든다 |
| 작동 원리 | 왜 그 구성이 과제를 푸는가 | 잘 붙는다 | 경도가 낮은 돌기가 암반 요철을 따라 변형해 실제 접지 면적이 커지고, 뒤꿈치는 높은 경도로 마모를 견딘다 |
| 효과 | 측정할 수 있는 결과 | 안전하다 | 젖은 화강암 판에서 측정한 앞꿈치 동마찰계수가 경도가 하나인 밑창보다 기준값 이상 높다 |
| 실시 형태 | 구체적인 재료·치수·공정 | - | 앞꿈치 고무 쇼어 A 50~60, 뒤꿈치 고무 쇼어 A 65~75, 이색 가황 성형 |

## 2. 발명 단위 나누기

- 서로 독립적으로 실시할 수 있고, 각각 다른 선행문헌과 비교해야 하는 구성은 다른 발명 단위다.
- 하나의 출원에 묶을지 나눌지는 발명의 단일성(하나의 총괄적 발명 개념)으로 판단한다. 묶기 어렵다고 판단하면 나눠 쓰고 이유를 적는다.

## 3. 발명 후보 확장

각 발명 단위를 다섯 축으로 넓혀 변형 실시 형태를 적는다. 변형례는 나중에 보정 근거와 회피 설계 차단에 쓰인다.

| 축 | 질문 |
| --- | --- |
| 재료 | 같은 기능을 내는 다른 재료군은? |
| 구조 | 층 위치, 영역 형상, 패턴을 바꾸면? |
| 공정 | 인쇄, 코팅, 라미네이션, 성형 중 어느 공정으로 만들 수 있나? |
| 작동 조건 | 다른 사용 조건(온도, 습도, 하중, 사용 환경)에서도 같은 효과가 나오나? |
| 용도 | 같은 원리를 다른 제품(작업화, 자전거 페달, 계단 미끄럼 방지재)에 쓸 수 있나? |

확장한 후보는 `[실현성 미확인]`을 붙이고, 확인 방법(간이 시험, 문헌)을 적는다.

## 4. 공개 이력 확인

발명신고서에 반드시 공개 이력 표를 둔다. 출원 전 공개는 신규성 상실 사유다.

| 공개 형태 | 날짜 | 범위 | 공지예외 대상 여부 |
| --- | --- | --- | --- |

자료에 공개 정보가 없으면 "확인 필요"로 남기고 발명자 질문에 넣는다.

## 5. 발명자 질문 목록

추론으로 채운 칸과 빈칸마다 질문을 만든다. 질문은 예·아니오가 아니라 값이나 사실을 묻는 형태로 쓴다. 예: "앞꿈치 돌기의 경도를 바꿔 가며 젖은 암반 마찰을 측정한 적이 있는가? 있으면 조건과 값은?"
