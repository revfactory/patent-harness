# 자유실시·침해 위험 분석

fto-analyst가 따르는 절차다. 등록 가능성(내가 특허를 받을 수 있는가)과 자유실시(내가 제품을 만들어 팔 수 있는가)는 다른 질문이다. 특허를 받아도 남의 존속 특허를 침해할 수 있으므로 두 분석을 따로 한다.

## 1. 존속 권리 추리기

검증 원장에서 아래 상태를 존속 권리로 분류한다.

| 상태 | 처리 |
| --- | --- |
| Active(등록 유지) | 대비 대상 |
| Pending(심사 중) | 대비 대상. 현재 청구항과 "등록 가능한 최대 범위 추정"을 함께 본다 |
| 분할출원 가능성이 있는 거절·심사 중 패밀리 | 대비 대상으로 표시하고 분할 여부 확인을 남긴다 |
| Expired, Ceased, Withdrawn, 거절 확정 | 자유 실시 기술 목록으로 보낸다 |
| 표시값 의심 | 원부 확인 전까지 대비 대상에 둔다. 소멸로 단정하면 위험을 놓친다 |

국가마다 표를 나눈다. 특허권은 등록한 나라 안에서만 효력이 있다(속지주의).

## 2. 대비

- 대상: 각 존속 권리의 독립항. 종속항은 독립항이 걸릴 때만 본다.
- 구성요소 완비 원칙: 실시 형태가 독립항의 모든 구성을 가져야 문언 침해다. 하나라도 없으면 문언 침해가 아니다.
- 균등 침해(한국 판례 요지): 구성이 다르더라도 ① 과제 해결 원리가 같고 ② 실질적으로 같은 작용효과를 내며 ③ 통상의 기술자가 쉽게 바꿀 수 있고 ④ 공지 기술이나 그로부터 쉽게 발명할 수 있는 것이 아니며 ⑤ 출원 과정에서 의식적으로 제외한 것이 아니면 침해가 될 수 있다.
- 간접 침해(제127조): 침해 물건 생산에만 쓰이는 부품을 공급해도 문제가 될 수 있다. 밑창 공급사와 신발 제조사를 나눠 판단한다.

## 3. 위험 등급

| 등급 | 기준 |
| --- | --- |
| 높음 | 문언 침해 가능성. 독립항 모든 구성 충족 |
| 중간 | 구성 하나가 다르지만 균등 가능성이 있음, 또는 심사 중 출원의 보정 범위에 들어갈 수 있음 |
| 낮음 | 구성이 둘 이상 다르고 균등 요건 ④·⑤로 막힘 |
| 해당 없음 | 대상 국가에 권리 없음, 또는 소멸 |
| 판단 보류 | 청구항 원문 미확인, 상태 의심 |

## 4. 회피 설계

위험 권리마다 빠뜨릴 수 있는 구성 하나를 찾아 회피안을 적는다. 회피안이 내 발명의 핵심 구성과 충돌하면 그 사실을 적는다. 이 경우 실시 허락이나 무효 자료 조사가 대안이다.

## 5. 자유 실시 기술

소멸 문헌에서 그대로 쓸 수 있는 기술을 정리한다. 단, 소멸 문헌의 기술을 쓴 제품이라도 그 위에 얹은 개량이 다른 존속 특허에 걸릴 수 있으므로 "소멸 기술 + 존속 권리 대비"를 함께 적는다.

## 존속 권리 목록(국가별)
## 권리별 대비표

## 회피 설계
