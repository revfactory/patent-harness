## 1. 번호 형식

Google Patents는 `국가코드 + 번호 + 종류코드` 형식을 쓴다. 404가 나면 아래 표로 형식을 바꿔 다시 시도한다. 표의 번호는 자릿수와 표기만 보여 주는 형식 예시다.

| 국가 | 문헌 | Google Patents 형식 | 비고 |
| --- | --- | --- | --- |
| KR | 공개특허 | KR1020180012345A → `KR20180012345A` | 출원번호(10-2018-0012345)와 공개번호 표기가 다르다 |
| KR | 등록특허 | `KR101234567B1` | 등록번호 10-1234567 |
| KR | 공개실용 | `KR20120001234U` | 20-2012-0001234 |
| KR | 등록실용 | `KR200412345Y1` | 20-0412345 |
| JP | 공개특허(헤이세이) | `JPH11123456A` | 특개평11-123456 |
| JP | 공개특허(쇼와) | `JPS6112345A` | 특개소61-12345 |
| JP | 공개특허(2000년 이후) | `JP2012123456A` | 특개2012-123456 |
| JP | 등록특허 | `JP5123456B2`, `JP7123456B1` | B1은 공개 전 등록 |
| JP | 공개실용(헤이세이) | `JPH0512345U` | 실개평5-12345 |
| JP | 등록실용 | `JP2512345Y2` | 실등 2512345 |
| JP | 공고실용(쇼와) | `JPH0412345Y2` | 실공평4-12345 |
| JP | 공표(PCT 번역) | `JPH05501234A` | 특표평5-501234 |
| US | 등록 | `US5960411A`(2001년 이전), `US6285999B1` | 2001년 이후 B1/B2 |
| US | 공개 | `US20150123456A1` | |
| CN | 실용신안 | `CN208123456U` | |
| CN | 발명 공개/등록 | `CN1xxxxxxxA` / `...B` | |
| EP | 공개/등록 | `EP1123456A1` / `EP1123456B1` | |
| WO | 국제공개 | `WO2015123456A1` | |

## 2. 데이터베이스별 접근

| 데이터베이스 | URL | 접근 | 쓰임 |
| --- | --- | --- | --- |
| Google Patents | `https://patents.google.com/patent/{번호}/{en|ko|ja}` | 스크립트 가능 | 서지, 청구항, 번역문, 인용 관계 |
| Google Patents 검색 | `https://patents.google.com/?q=(...)&before=priority:20200101` | WebFetch로 결과가 잘 안 보일 수 있음 | 키워드 검색은 WebSearch에 `site:patents.google.com`을 붙여 대체 |
| Espacenet | `https://worldwide.espacenet.com/patent/search?q=pn%3D{번호}` | 자바스크립트 의존, 열람 제한 가능 | 패밀리, INPADOC 법적 상태 |
| KIPRIS | `https://www.kipris.or.kr` | 자동 접근이 막히는 경우가 많음 | 한국 원부, 행정처리 이력 |
| J-PlatPat | `https://www.j-platpat.inpit.go.jp` | 자동 접근이 막히는 경우가 많음 | 일본 경과정보, F-term 검색 |
| USPTO Patent Center | `https://patentcenter.uspto.gov` | 제한적 | 미국 포대(파일 래퍼) |

직접 접근이 막힌 곳은 "변리사·조사기관 확인 필요" 목록으로 넘긴다.

## 3. 분류코드

- IPC/CPC: 등산화 밑창 예시로 A43B 13/22(미끄럼 방지·내마모 밑창), A43B 13/04(플라스틱·고무 밑창), A43C 15/00(미끄럼 방지 장치), C08L 9/06(스티렌 공중합 고무 조성물).
- 일본 F-term: 분야의 테마 코드를 J-PlatPat의 FI·F-term 조회에서 IPC로 찾아 확인한 뒤 쓴다.
- 분류 검색은 키워드에 걸리지 않는 표현의 문헌을 찾는 데 쓴다. 분류만으로 찾으면 결과가 많으므로 핵심 키워드 하나를 함께 건다.

## 4. 검색식 예

```
(outsole OR sole OR 靴底 OR 鞋底 OR 밑창) AND (hardness OR durometer OR 硬度 OR 경도) AND (forefoot OR 前足 OR 앞꿈치)
CPC=A43B13/22 AND (rubber NOT leather)
assignee:("{출원인 A}" OR "{출원인 B}") AND outsole AND wet, priority:2015-2026
```

- 날짜 조건을 함께 쓴다. 출원 예정일 이전에 공개된 문헌만 선행기술이다.
- 출원인 검색은 업계 주요 기업(완제품 제조사, 부품 전문 업체, 소재 회사)을 나눠 실행한다.
